# Rakshya App Landing Page 🛡️

The official landing page for **Rakshya**, hosted at [rakshyaapp.github.io](https://rakshyaapp.github.io). This site serves as the central hub for users to learn about the app, view demonstrations, and download the latest Android releases.

## 🚀 Features

- **Direct Downloads:** Easy access to the latest `.apk` releases (v3.0.0).
- **Video Demo:** Watch the app in action via the embedded `demo.mp4`.
- **Responsive Design:** Optimized for both mobile and desktop viewing.
- **Fast Loading:** Built with lightweight HTML, CSS, and Vanilla JS for maximum performance.

## 📥 How to Install (For Users)

1.  Navigate to the **[Releases](https://www.google.com/search?q=https://github.com/rakshyaapp/rakshyaapp.github.io/releases)** section.
2.  Download the latest `.apk` file.
3.  On your Android device, enable "Install from Unknown Sources" in settings.
4.  Open the file and follow the installation prompts.
